# BB variants

Adjacent busy-beaver-style systems explored alongside the main holdout work.

- `CET/` — Catch-Em-Turing and Multi-Catch-Em-Turing (CET/MCET) simulator, web studio and search engine. See `CET/README.md` for results and usage.
- `ATS/` — Absorbing Tag System (ATS / Tagy Tag), a Tiny Tag / cyclic-tag variant with self-absorbing function tokens. See `ATS/README.md` for the rule set, simulator, length-8 probe, 307-step length-8 result, certified Loom BMO machine, length-14 Rattle and length-32 Grove cryptid candidates.
- `DTM/` — Double Turing Machines (`DTM(n,m)`, `DTM(n,m,a)`, `DTM(n,m,a,b)`) web studio, HTTP server, C/Python search engines, and champion table. See `DTM/README.md` for results and usage.
- `GlyphCalc/` — GlyphCalc Busy Beaver (GCBB): a language-level BB-shaped proposal over a closed string/loop core, with a reference step-counting harness. See `GlyphCalc/README.md`.
