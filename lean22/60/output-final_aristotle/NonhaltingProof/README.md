# BB25 fractal: closed mathematical nonhalting proof

Machine: `1RB2LA3LB4LB---_0LA4LB3RA4LA0RB`.

Read **PROOF.md** for the complete all-rank mathematical argument. Its core is a simultaneous induction on reset and triangle rectangles, with the next transient prefix obtained by cutting a derived echo.

This package is not a kernel-checked Lean/Rocq development. The accompanying original Lean project is unchanged, including its admitted `never_halts`. **FORMALIZATION.md** describes the concrete remaining translation and audit work.

Files:

- `PROOF.md`: mathematical proof, including the ordinary-execution nonhalting reduction.
- `proof.py`: orbit-independent constructive rectangle generator and direct cell checker.
- `test_proof.py`: rank/parameter/mutation checks.
- `audit.py`: independently coded whole-block interpreter and right-engine checks.
- `verification.json`, `independent_audit.json`: executed test results.
- `rank7_triangle.json`: a finite width-2059 rectangle, generated by the induction rather than extracted from an ordinary orbit.
- `FORMALIZATION.md`: a handoff for completing the Lean formalization.

Requires Python 3.10 or later and only its standard library:

```bash
python test_proof.py
python audit.py
python proof.py --check rank7_triangle.json
python proof.py --rank 5 --kind reset --m 2 --q 3 --k 4
```

All-rank validity comes from the induction in the proof, not from finite testing. The direct checkers provide additional audits of its explicit construction. Large ranks expand finite words eagerly and can consume substantial memory; the default tests stop at rank 7.
