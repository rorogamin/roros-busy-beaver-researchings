# Index 17: the C3 obligation is not yet a TM nonhalting proof

Machine: `1RB---0RB0LA2RA_2LB2LA3RA4LB0LB`.

External source inspected:
`rwst/bbchallenge/1RB---0RB0LA2RA_2LB2LA3RA4LB0LB/Dio.lean` and
`BackwardTrace.lean` on GitHub `main`.

## What C3 actually says

`Dio.lean` defines an arithmetic era recurrence and states:

```lean
theorem C3 (V n d : Nat) (h : ArithReachable V n d) :
    ¬ ∃ m, V + 2^n + 3^d = 2^m := by
  sorry
```

`ArithReachable` is membership in `eraSeq`, generated by `nextEra`.
C3 is therefore a statement about the **arithmetic recurrence**, not directly
about the Turing machine.

The intended chain is:

1. `era_bad_iff_diophantine`: a bad era end is equivalent to
   `V + 2^n + 3^d` being a power of two.
2. `C3`: no arithmetically reachable entry has that property.
3. `arith_reachable_iff_TM`: arithmetic reachability equals TM reachability.
4. `BackwardTrace.all_s3_odd_overflow_halts`: a bad state would halt.

## Why closing C3 alone would not close index 17

`Dio.lean` itself says `nextEra` is only partly rigorous:

- the `V_end % 2 = 0` branch is backed by `machine.overflow_odd`;
- the `V_end % 4 = 1` branch is a heuristic approximation;
- the `k >= 2` branch is a heuristic approximation and is "disproved in
  general" by a concrete simulation.

More importantly, the bridge theorem

```lean
theorem arith_reachable_iff_TM (V n d : Nat) :
    ArithReachable V n d ↔ IsReachableEraEntry V n d := by
  sorry
```

is marked **currently false as stated** in the source comments, because the
k=1 and k>=2 branches do not faithfully model the TM. Thus a proof of C3
would prove a property of an incorrect recurrence, not nonhalting of the raw
machine.

There is a second open obligation in `BackwardTrace.lean`:
`all_s3_odd_overflow_unreachable_from_init` is itself `sorry`, and
`cycle_nonzero_pred_bad_state` is also `sorry`. C3 is not the only gap.

## Attempted computational checks

A Python transcription of `nextEra` was run on the first 5,000 arithmetic
entries. No power-of-two sum appeared in those entries. This is only a finite
check: it is not a proof, and it does not validate the TM bridge.

Small-modulus scans found many entries whose `V + 2^n + 3^d` is a non-residue
of the power-of-two subgroup modulo various tested primes, but no single
tested modulus covered all entries. In particular, a simple mod-8 argument
is not a complete invariant: 515 of the first 5,000 entries have `n >= 3` and
`V + 3^d = 0 (mod 8)`, so the necessary residue condition holds there.

The raw TM was also inspected at the published 117-step canonical entry. The
published `Dio.lean` E0 is `(2,2,4)` at the first pad=1 era entry; the
canonical at step 117 is a pad=0 cycle entry and is not a counterexample to
that E0 statement. No direct contradiction was found at that checkpoint.

## Conclusion

The honest status is:

- C3 is an open arithmetic lemma about a **heuristic** recurrence.
- The theorem needed to connect that recurrence to the TM is also open and
  explicitly described as false in its current form.
- Porting C3 to Rocq, or proving it, would not by itself give a raw-machine
  nonhalting theorem.
- The next meaningful index-17 task is to repair `nextEra` and prove the
  k=1 and k>=2 branches, not merely to attack the displayed C3 equation.
